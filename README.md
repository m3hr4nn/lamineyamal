# Hamine Yamal Checker

A static, browser-only YAML to JSON/XML converter for GitHub Pages.

## Publish on GitHub Pages

1. Upload all four project files to the root of the `lamineyamal` repository.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then click **Save**.

The site will be available at:

`https://YOUR-USERNAME.github.io/lamineyamal/`

The specifically named page will be available at:

`https://YOUR-USERNAME.github.io/lamineyamal/hamine-yamal-checker.html`

## Notes

- Conversion happens locally in the browser; YAML content is not uploaded.
- The page loads `js-yaml` from jsDelivr, so the first visit requires internet access.
- Press `Ctrl+Enter` (or `Cmd+Enter`) to convert from the editor.
